# somepeople reading club — 카드뉴스 제작 폴더

## 자동 게시
이 저장소는 GitHub Pages로 공개 호스팅되며(`https://dlcjdtn456789-svg.github.io/somepeople-reading-club/`),
`../automation/publish_daily.js`가 인스타그램 Graph API로 오늘 날짜 폴더를 자동 캐러셀 게시합니다.
설정 방법은 [`automation/README.md`](../automation/README.md) 참고 — 액세스 토큰 발급 전까지는 수동 게시 필요.

## 구조
```
카드뉴스/
  _brand/palette.md      브랜드 컬러·폰트·레이아웃 가이드 + PNG 생성 스크립트
  YYYY-MM-DD/             하루치 카드뉴스 (날짜별 폴더, 1건씩)
    01.html ~ 07.html     슬라이드 원본 (수정 가능)
    01.png  ~ 07.png      인스타그램 업로드용 최종 이미지 (1080x1350)
    caption.txt           인스타그램 캡션 + 해시태그
```

## 발행 순서 (응답자 생기기 전 — 브랜드 서사 시리즈, 10편)
아직 독자 응답이 없는 런칭 초기 구간이라, 실제 독서 경험 콘텐츠(오늘의 독서 등) 대신
브랜드 자체를 소개하는 서사 시리즈를 먼저 채워뒀습니다. 순서대로 매일 발행 추천.

| 날짜 | 폴더 | 주제 |
|---|---|---|
| 1 | `2026-07-17` | 프로젝트 선언문 (프로필 고정용) |
| 2 | `2026-07-18` | 브랜드서사① 왜 시작했는가 |
| 3 | `2026-07-19` | 브랜드서사② 이름의 의미 |
| 4 | `2026-07-20` | 브랜드서사③ 왜 하필 책인가 |
| 5 | `2026-07-21` | 작성방법① 이렇게 기록해보세요 |
| 6 | `2026-07-22` | 작성방법② 무엇을 남길지 모르겠다면 |
| 7 | `2026-07-23` | 기록이유① 왜 감정을 기록해야 할까 |
| 8 | `2026-07-24` | 기록이유② 흘러가는 것과 남는 것 |
| 9 | `2026-07-25` | 효과 — 기록이 남기는 것 |
| 10 | `2026-07-26` | 마무리 — 당신의 이야기를 기다립니다 (9편 요약 + CTA) |

이 10편이 소진된 뒤(2026-07-27~)부터는 실제 응답자가 생겼는지에 따라 갈립니다:
- **아직 응답자가 없다면** — 브랜드 서사를 더 파고들거나(예: 책 선정 기준, 명함 디자인 비하인드),
  "오늘의 독서" 콘텐츠로 먼저 전환해 실제 독서 기록을 쌓아가는 방법을 추천합니다.
- **응답자가 생겼다면** — 아래 "앞으로 매일 한 건씩 만드는 법"의 4가지 유형으로 전환.

## 앞으로 매일 한 건씩 만드는 법 (실사용 단계)
이 프로젝트는 그날 실제로 읽은 책 · 카페 · 감정을 다루는 콘텐츠라, 브랜드 서사 시리즈 이후부터는
**그날의 재료**가 있어야 카드뉴스를 만들 수 있습니다. 아래 중 있는 만큼만 전달해주시면 바로 제작합니다.

- 그날 읽은 책 제목 / 저자
- 읽은 장소 (카페 이름 등, 비공개 원하면 생략)
- 인상 깊었던 구절이나 그날 느낀 감정
- (있다면) 책을 건넨 순간의 짧은 소회
- (있다면) 돌아온 독자 경험 — 누가 언제 무엇을 보내왔는지

콘텐츠 유형은 4종 중 하나로 골라서 요청하시면 됩니다:
1. **오늘의 독서** — 그날 읽은 책 + 감정/구절
2. **전달의 기록** — 누군가에게 책을 건넨 순간
3. **돌아온 경험** — 독자가 보내온 감상 소개 (전달일~회신일 경과 표기)
4. **연결망 지도** — 지금까지 책이 이동한 장소 아카이빙 (분기별)

새 날짜 폴더를 만들고 위 재료를 주시면, `_brand/palette.md`의 디자인 기준에 맞춰
슬라이드를 제작하고 PNG로 캡처해서 넣어드립니다.
